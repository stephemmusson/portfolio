# Stephen Musson Portfolio

Static one-page portfolio and UX Arcade.

## Site files

The publishable website is in `dist/`.

## Site5 deployment

The deployment workflow is manual until Site5 has been tested. It requires these GitHub Actions secrets:

- `SITE5_SERVER`
- `SITE5_USERNAME`
- `SITE5_PASSWORD`
- `SITE5_REMOTE_DIR`

Use a restricted FTPS account where possible. Do not store hosting credentials in repository files.
